# Hello
this is the version history of LuminOS. this repository was made to show all the builds of the LuminOS, its changelog and all the iso's download links.<br>

## Milestone 1 Codenamed "Phantom"
this is the first betas that everyone can download it. Also, this milestone is made of "resource testing" builds, like 2093<br>

### Build 2093
this is officially the first LuminOS build. The build was compiled by NyanRay64 and RiceTheDev.

#### Changelog
##### it already have
Plasma as main DE  
tilix as main terminal  
nala as main package manager  
beta LIGHT wallpaper as default (dark doesnt exist yet)  
KDE discover instead of GNOME software  
Dotnet Runtime & Framework  
##### it doesnt have yet  
beta DARK wallpaper  
GNOME sushi  
LuminSDK  
Neofetch logo  
##### bugs  
on first startup it starts on GNOME, and you need to select KDE plasma manually (may be fized on 2097)  
on default wallpaper, when you select "Breeze Dark" the wallpaper changes to Breeze default wallpaper (may be fixed on 2097)
